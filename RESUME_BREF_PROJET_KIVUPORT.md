# Résumé bref du projet KivuPort

## Thème

**Système de gestion portuaire intelligent : réservation en ligne, suivi des embarquements, génération de rapports, interface mobile.**

## Présentation

KivuPort est une application web destinée à moderniser la gestion des traversées maritimes sur le lac Kivu. Elle centralise les informations liées aux ports, quais, bateaux, voyages, pavillons, clients, réservations et paiements dans une seule plateforme.

Grâce à KivuPort, un client peut consulter les voyages disponibles, choisir un pavillon, effectuer une réservation en ligne, suivre son statut et payer par mobile money. Après la confirmation du paiement, un reçu PDF avec code QR est généré automatiquement.

L'administrateur dispose d'un tableau de bord lui permettant de gérer les réservations, les clients, les bateaux, les voyages, les ports, les quais et les pavillons. Il peut ajouter, modifier ou supprimer les données, y compris effectuer certaines actions de manière multiple sur les réservations.

Le système fournit également des statistiques et des rapports PDF professionnels. Ces rapports présentent les réservations, les statuts, les tendances et les recettes séparées en CDF et en USD, selon les paiements enregistrés.

KivuPort est responsive et peut être utilisé sur ordinateur, tablette ou téléphone. Son interface comprend un mode clair et un mode sombre, une navigation simplifiée et des composants adaptés aux différents écrans.

## Technologies utilisées

Le projet utilise principalement Next.js, React, TypeScript, Tailwind CSS, Supabase, Chart.js, Framer Motion et pdf-lib.

## Importance du projet

KivuPort permet de réduire les erreurs liées à la gestion manuelle, d'accélérer les réservations, d'améliorer le suivi des paiements et d'offrir aux responsables portuaires une meilleure visibilité sur les activités. Il constitue une solution moderne, centralisée et évolutive pour la gestion des opérations maritimes.
